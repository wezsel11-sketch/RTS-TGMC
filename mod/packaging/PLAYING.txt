TGMC: Marines vs Xenos (version @VERSION@)
An OpenRA real-time strategy mod made from TerraGov Marine Corps, the SS13 game.
Source and instructions: https://github.com/wezsel11-sketch/RTS-TGMC

START
  Windows: double-click TGMC.exe. If Windows SmartScreen warns about an unknown publisher, choose "More info", then "Run anyway".
  Linux:   run ./TGMC.sh. Needs a desktop with OpenGL 3.3 (any graphics driver from the last ten years).
  Then Singleplayer -> Skirmish, pick a map, add a Skirmish AI to the other slot, Start Game.
  Settings, saves and logs are kept by OpenRA: Documents\OpenRA on Windows, ~/.config/openra on Linux.
